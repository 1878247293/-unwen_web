# 环境脚本使用说明

本目录包含自动化脚本，用于快速配置和启动后端环境。

## 📁 脚本文件

### 激活环境脚本
- `activate.sh` - Linux/Mac 激活脚本
- `activate.bat` - Windows 激活脚本

### 配置环境脚本
- `setup.sh` - Linux/Mac 配置脚本（需在激活环境后运行）
- `setup.bat` - Windows 配置脚本（需在激活环境后运行）

## 🚀 使用方法

### Linux/Mac 用户

#### 第一步：激活虚拟环境

```bash
cd backend
bash activate.sh
```

**功能**：
- 自动检测虚拟环境是否存在
- 如不存在则自动创建 venv
- 激活虚拟环境
- 启动新的 shell 会话保持激活状态

#### 第二步：配置环境

在激活的虚拟环境中运行：

```bash
bash setup.sh
```

**功能**：
- 升级 pip
- 安装所有 Python 依赖包
- 创建必要的数据目录
- 初始化 SQLite 数据库
- 创建默认管理员账号

#### 第三步：启动后端

```bash
python app/main.py
```

## 🔧 故障排除

### 问题1：激活脚本无法执行（Linux/Mac）

**错误**：`Permission denied`

**解决**：
```bash
chmod +x activate.sh setup.sh
```

### 问题2：虚拟环境创建失败

**错误**：`python: command not found` 或 `python3: command not found`

**解决**：
- 确保已安装 Python 3.9+
- Linux/Mac 使用 `python3`
- Windows 使用 `python` 或 `py`

### 问题3：依赖安装失败

**可能原因**：
- 网络问题
- pip 版本过旧

**解决**：
```bash
# 升级 pip
pip install --upgrade pip

# 使用国内镜像（可选）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题4：数据库初始化失败

**检查**：
- 确保在虚拟环境中
- 确保所有依赖已安装
- 查看错误信息

**重新初始化**：
```bash
rm data/database.db  # 删除现有数据库
python scripts/init_db.py  # 重新初始化
```

### 问题5：端口被占用

**错误**：`Address already in use: 8000`

**解决**：
修改 `.env` 文件中的端口：
```env
PORT=8001
```

## 💡 提示

### 退出虚拟环境

在激活的虚拟环境中输入：
```bash
deactivate
```

### 重新进入虚拟环境

```bash
# Linux/Mac
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 清理重装

```bash
# 删除虚拟环境
rm -rf venv  # Linux/Mac
rmdir /s venv  # Windows

# 删除数据库
rm data/database.db  # Linux/Mac
del data\database.db  # Windows

# 重新开始
bash activate.sh  # Linux/Mac
activate.bat     # Windows
```

## 📝 脚本说明

### activate.sh / activate.bat

**功能**：
1. 检测虚拟环境是否存在
2. 不存在则创建新的虚拟环境
3. 激活虚拟环境
4. 保持终端/CMD打开

**注意**：
- 这个脚本会启动新的 shell 会话
- 关闭终端窗口即退出虚拟环境

### setup.sh / setup.bat

**功能**：
1. 检查虚拟环境是否已激活
2. 升级 pip 到最新版本
3. 安装 requirements.txt 中的所有依赖
4. 创建数据存储目录
5. 运行数据库初始化脚本
6. 显示默认管理员账号信息

**前置条件**：
- 必须在激活的虚拟环境中运行
- 需要网络连接（下载依赖包）
