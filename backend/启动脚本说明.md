# 🚀 后端启动脚本

## 📂 所有脚本一览

```
backend/
├── start.sh / start.bat           ⭐ 一键启动（推荐）
├── activate.sh / activate.bat     🔧 激活虚拟环境
├── setup.sh / setup.bat           📦 配置环境
└── 脚本使用说明.md                📖 详细使用文档
```

---

## ⭐ 推荐：一键启动

### Linux/Mac
```bash
bash start.sh
```

### Windows
```cmd
start.bat
```

**功能**：自动完成环境配置和服务启动，无需任何其他操作！

**适用场景**：
- ✅ 首次启动
- ✅ 日常启动
- ✅ 快速部署

---

## 🛠️ 常见操作

### 停止服务

在终端按 `Ctrl + C`

### 退出虚拟环境

```bash
deactivate
```

### 重新安装依赖

```bash
bash activate.sh  # 激活环境
bash setup.sh     # 重新配置
```

### 重置数据库

```bash
rm data/database.db        # Linux/Mac
del data\database.db       # Windows

python scripts/init_db.py  # 重新初始化
```

### 清理重装

```bash
# 删除所有生成的文件
rm -rf venv data .setup_done  # Linux/Mac
rmdir /s venv data            # Windows
del .setup_done               # Windows

# 重新开始
bash start.sh  # Linux/Mac
start.bat      # Windows
```

## 🐛 故障排除

### 问题：脚本无法执行（Linux/Mac）

**错误信息**: `Permission denied`

**解决方案**:
```bash
chmod +x *.sh
```

### 问题：Python命令找不到

**错误信息**: `python: command not found`

**解决方案**:
- Linux/Mac: 使用 `python3` 替换 `python`
- Windows: 安装 Python 并添加到 PATH

### 问题：端口被占用

**错误信息**: `Address already in use: 8000`

**解决方案**:
编辑 `.env` 文件，修改端口：
```env
PORT=8001
```

### 问题：依赖安装失败

**解决方案**:
```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```
