# 🚀 前端启动脚本

## 📂 所有脚本一览

```
frontend/
├── start.sh       ⭐ 一键启动（推荐）
├── setup.sh       📦 配置环境（安装依赖）

└── 脚本使用说明.md 📖 本文档
```

---

## ⭐ 推荐：一键启动

```bash
bash start.sh
```

**功能**：自动完成环境配置和服务启动，无需任何其他操作！

**适用场景**：
- ✅ 首次启动
- ✅ 日常启动
- ✅ 快速开发

**启动后访问**: http://localhost:5173

---

## 📦 配置环境

如果只想安装依赖，不启动服务：

```bash
bash setup.sh
```

**功能**：
- 检查 Node.js 环境
- 自动使用淘宝镜像加速下载
- 安装所有 npm 依赖包
- 可选择清理旧依赖重新安装

---

## 🗑️ 清理重装

如果需要清理并重新安装依赖：

```bash
bash clean.sh
```

**功能**：
- 删除 node_modules
- 删除 package-lock.json
- 删除 dist 构建输出
- 删除配置标记

**使用场景**：
- 依赖损坏
- 版本冲突
- 完全重装

---

| 脚本 | 功能 | 适用场景 | 执行时间 |

## 🐛 故障排除

### 问题：脚本无法执行

**错误信息**: `Permission denied`

**解决方案**:
```bash
chmod +x *.sh
```

### 问题：Node.js 未安装

**错误信息**: `node: command not found`

**解决方案**:
1. 访问 https://nodejs.org/
2. 下载并安装 Node.js 16+
3. 重启终端

### 问题：npm 安装速度慢

**已自动解决！**

项目已配置使用淘宝镜像（`.npmrc`文件），自动加速下载。

如需恢复官方源：
```bash
# 删除项目配置文件
rm .npmrc

# 或编辑 .npmrc，修改为：
registry=https://registry.npmjs.org
```

### 问题：端口被占用

**错误信息**: `Port 5173 is already in use`

**解决方案**:

方法1：关闭占用端口的程序
```bash
# 查找占用端口的进程
lsof -i :5173  # Mac/Linux
netstat -ano | findstr :5173  # Windows

# 结束进程
kill -9 [PID]  # Mac/Linux
```

方法2：修改端口
编辑 `vite.config.js`:
```javascript
export default defineConfig({
  server: {
    port: 5174,  // 改为其他端口
  }
})
```

### 问题：依赖安装失败

**常见原因**：
- 网络问题
- npm 版本过旧
- 磁盘空间不足

**解决方案**：

1. 更新 npm
```bash
npm install -g npm@latest
```

2. 清理缓存
```bash
npm cache clean --force
```

3. 使用淘宝镜像
```bash
npm install --registry=https://registry.npmmirror.com
```

4. 重装
```bash
bash clean.sh
bash setup.sh
```

### 问题：页面无法访问后端 API

**检查清单**：
- ✅ 后端是否已启动在 http://localhost:8000
- ✅ 检查浏览器控制台是否有错误
- ✅ 检查 `vite.config.js` 代理配置

## 📞 常见问题

### 前端和后端需要同时启动吗？

是的！前端需要调用后端 API，所以需要：
1. 终端1：运行 `cd backend && bash start.sh`
2. 终端2：运行 `cd frontend && bash start.sh`

### 修改代码后需要重启吗？

不需要！Vite 支持热模块替换（HMR），修改代码后浏览器会自动更新。

### 如何部署到生产环境？

```bash
# 构建生产版本
npm run build

# 生成的文件在 dist/ 目录
# 可以部署到任何静态服务器（Nginx、Apache、CDN等）
```

### 国内网络如何加速？

**已自动配置淘宝镜像！** 无需手动设置。

项目包含 `.npmrc` 配置文件，自动使用国内镜像源加速下载。
