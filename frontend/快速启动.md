# 前端快速启动

## 最简单的方式 ⭐

```bash
cd frontend
bash start.sh
```

就这么简单！脚本会自动：
1. 检查 Node.js 环境
2. 安装依赖（首次运行，自动使用淘宝镜像加速）
3. 启动开发服务器

**访问**: http://localhost:5173

---

## 常用命令

| 操作 | 命令 |
|------|------|
| 一键启动 | `bash start.sh` |
| 仅安装依赖 | `bash setup.sh` |
| 清理重装 | `bash clean.sh` |
| 停止服务 | 按 `Ctrl+C` |

---

## 开发流程

### 第一次启动

```bash
cd frontend
bash start.sh    # 会自动安装依赖并启动
```

### 日常开发

```bash
cd frontend
bash start.sh    # 或直接 npm run dev
```

### 依赖有问题

```bash
cd frontend
bash clean.sh    # 清理
bash setup.sh    # 重装
```

## 前后端联调

**终端1** - 后端：
```bash
cd backend
bash start.sh
# 访问: http://localhost:8000/docs
```

**终端2** - 前端：
```bash
cd frontend
bash start.sh
# 访问: http://localhost:5173
```

前端的 `/api/*` 请求会自动代理到后端 `http://localhost:8000/api/*`

## 故障排除

### Node.js 未安装？

下载安装: https://nodejs.org/
需要版本: >= 16

### 端口被占用？

编辑 `vite.config.js`，修改端口：
```javascript
server: {
  port: 5174,  // 改为其他端口
}
```

### npm 下载慢？

已自动配置淘宝镜像，无需手动设置！

如需恢复官方源：
```bash
npm config set registry https://registry.npmjs.org
```
